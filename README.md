# CartoVote: Municipal Geo-Questionnaire

A lightweight, browser-based spatial survey tool designed for municipal planning and community feedback. This tool allows citizens to answer survey questions and pin-point specific locations on a map to provide geographic context to their feedback.

## 🚀 Features
* **Interactive Mapping:** Powered by [Leaflet.js](https://leafletjs.com/).
* **Point-of-Interest Capture:** Users can drop pins to indicate areas of concern or suggestion.
* **Responsive Design:** Pure HTML5, CSS3, and Vanilla JavaScript—no heavy frameworks required.
* **Civic Focused:** Optimized for urban planning, transit feedback, and local government use.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3
* **Interactivity:** JavaScript (ES6+)
* **Maps:** Leaflet.js
